# Chamfer

Chamfer bevels edges with a flat cut — the angled transition machinists put on every edge a hand or a part will meet.

## In the viewport

1. Click **Chamfer** on the toolbar. A small panel opens with one field, **Distance** (default 1).
2. Click the edges in the viewport. <kbd>Ctrl</kbd> / <kbd>Shift</kbd> adds edges; right-click a pick for the multi-select menu (tangent chain, same-type edges, the feature's buckets such as *Extrude End Edges*, *Select other*).
3. Type the distance. The statement is written with the resolved selection.

## Targeting edges in code

Same conventions as [fillet](/docs/3d-operations/fillet): pass edges after the distance, or chamfer the last selection:

```js
// Direct
chamfer(2, e.sideEdges())

// With select
import { select } from 'fluidcad/core';
import { edge } from 'fluidcad/filters';

select(edge().onPlane("xy", 30))
chamfer(4)
```

Several edge selections at once:

```js
chamfer(2, e.endEdges(), e.sideEdges())
```
