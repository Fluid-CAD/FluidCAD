# Selection & Filters

Fillet, chamfer, shell, color, connectors and sketches on faces all need to be told *which* faces or edges. In the viewport you click them. In the file that click becomes one of three things: an accessor on the feature that made the geometry, a `select()` with a filter, or a filter passed straight to the operation. This page covers how picking works and what it writes.

## Picking in the viewport

- **Click** a face, edge or vertex to select it. The selection info overlay names what you picked and the feature that produced it.
- <kbd>Ctrl</kbd> / <kbd>Shift</kbd> + click adds to the selection.
- **Right-click** a picked entity for the multi-select menu, fetched from the model:
  - the **tangent chain** the edge belongs to (a filleted outline in one go),
  - edges or faces of the **same type**, or of **equal measure** (all Ø6 holes),
  - the producing feature's **buckets** — *Extrude End Edges*, *Side Faces* … — and **Select other**, which lists the feature's remaining buckets when your pick was, say, a start edge.
  - Hovering a menu item previews exactly what clicking it would select.
- With a pick tool armed (**Fillet**, **Chamfer**, **Shell**, **Sketch**, **Offset**), the picks go straight into that tool's statement.

A plain click with no tool armed is also the [measure](/docs/user-interface#measuring) gesture.

### What the pick writes

The pick tools resolve your clicks to the most stable reference they can:

| Your picks | Written as |
|------------|------------|
| A whole bucket of one feature (all end edges of an extrude) | `fillet(5, e.endEdges())` |
| A subset of a bucket | `fillet(5, e.endEdges(0, 2))` — by index |
| Entities a filter describes better | `select(edge().onPlane("xy", 30))` then the operation |
| A face for a sketch or connector | `sketch(e.endFaces(), …)`, `connector('top', e.endFaces())` |

Feature variables (`const e = extrude(30)`) are introduced by the writer when a statement needs one.

## Direct selection

Every operation returns an object whose accessors pick its own faces and edges:

```js
const e = extrude(30)

fillet(5, e.endEdges())        // top edges
fillet(3, e.startEdges())      // bottom edges
shell(-4, e.endFaces())        // remove top face and hollow
color("blue", e.sideFaces())   // color the sides
```

By index when there are several:

```js
e.sideFaces(0)                 // the first side face
e.sideFaces(2)                 // the third side face
```

## The select function

For more control, use `select()` with filters from `fluidcad/filters`:

```js
import { select } from 'fluidcad/core';
import { edge, face } from 'fluidcad/filters';

select(edge().verticalTo("xy"))
fillet(3)
```

`select()` finds all matching geometry in the scene and stores it as the **last selection**. The next operation that needs a selection (fillet, chamfer, shell, color …) uses it and consumes it. The one exception is [`color()`](/docs/appearance/color), which changes no geometry: it takes the selection as its target but leaves it intact, so a selection passed to `color()` can still be passed to a later feature.

## Edge filters

Import `edge` (and `face` if using `belongsToFace`) from `fluidcad/filters` and chain filter methods. Chained calls AND together:

```js
import { edge, face } from 'fluidcad/filters';
```

### By direction

```js
edge().verticalTo("xy")        // edges perpendicular to the XY plane
edge().parallelTo("xz")        // edges parallel to the XZ plane
```

A curved edge other than a circle or an arc — an ellipse, a spline — is parallel to a plane when it lies in a plane parallel to it. A curve that winds through space, such as a helix, lies in no plane and is parallel to none, and no curve is `verticalTo()` a plane: only a straight edge can be.

### By position

```js
edge().onPlane("xy", 30)                   // edges that lie on the XY plane at height 30
edge().onPlane("yz", { offset: 50, bothDirections: true }) // edges on YZ plane at offset ±50
edge().above("xy", 10)                     // edges entirely above z = 10
edge().below("xz", { partial: true })      // edges at least partly below XZ: on its +y side, as XZ's normal points along −y
```

`onPlane()` keeps an ellipse or a spline when the one plane it lies in is that plane. `above()` and `below()` judge a line, a circle or an arc by its two ends, and any other edge by how far it really reaches, so a spline that sags below the plane between its ends is not above it.

### Relative to another feature

A plane, half-space, or parent-face test can take a feature's face group instead of a number. The reference follows the feature through later edits, so no offset is baked into the selector:

```js
const base = extrude(10);
edge().onPlane(base.endFaces())            // edges on the plane of the base's top faces
edge().above(base.endFaces())              // edges entirely above that plane
edge().above(base.endFaces(), 5)           // … offset 5 along its normal
edge().belongsToFace(base.endFaces())      // edges bounding one of those faces (as built)
```

### By rank and extremes

Rank filters compare an edge with the other candidates instead of with a number. They keep the whole tied group — every edge whose center of mass sits at the extreme within tolerance — so a box's `farthest("z")` is its four top rim edges:

```js
edge().farthest("z")           // the topmost layer of edges (by center of mass)
edge().nearest("x")            // the layer with the least x
edge().farthest("-y")          // negative axes, vectors ([1, 1, 0]) and axes work too
edge().nth("z", 1)             // the second layer from the bottom; nth("z", -1) is farthest("z")
edge().largest()               // the longest edges (ties included)
edge().smallest("radius")      // the circles / arcs of least radius
```

Chain order is evaluation order: `edge().line().farthest("z")` ranks only the lines, while `edge().farthest("z").line()` keeps the lines within the overall top layer.

### By convexity

```js
edge().convex()                // outer corners — the usual fillet targets
edge().concave()               // inner corners — where a boss meets its base
edge().smooth()                // tangent transitions, such as a fillet's boundaries
```

### By shape

```js
edge().circle()                // circular edges
edge().arc()                   // arc-shaped edges
edge().line()                  // straight edges
edge().line(10)                // straight edges with length 10
edge().ellipse()               // elliptical edges, full or arcs
edge().ellipse().open()        // elliptical arcs only
edge().spline()                // free-form edges: a sketch spline, a loft's free-form rim, a helix
edge().closed()                // edges that return to their start: full circles, ellipses, closed splines
edge().spline().planar()       // splines that lie in one plane, within a millionth of a millimetre (a helix does not)
```

Shapes are told by geometry, not by how the kernel stores the curve: the straight and round edges a loft or an imported STEP file stores as B-splines are still lines, arcs, circles and ellipses. Only an edge that is none of those is a `spline()`.

### By parent face

```js
edge().belongsToFace(face().circle())         // edges on circular faces
edge().belongsToFace(face().parallelTo("xy")) // edges on faces parallel to XY

// or pass a scene object directly
const topFaces = select(face().onPlane("xy", 30));
edge().belongsToFace(topFaces)                // edges belonging to those faces
```

### By topology

These name an edge by the faces around it — no size, no position — so they hold through dimension edits, and they work the same on solids and surfaces:

```js
edge().boundary()                              // the open rim of a surface: edges that bound one face of their body
edge().between(face().planar(), face().cylinder())  // where flat faces meet round ones, in either order
edge().between(wall.sideFaces(), cap.endFaces())    // where two features' faces meet
edge().between(face(), face())                 // every interior edge (never a seam, never an open rim)
edge().boundaryOf(pocket.internalFaces())      // the perimeter of a group of faces: a pocket's mouth
edge().boundaryOf(face().cylinder())           // the rims of every group of cylindrical faces
```

`boundary()` is the same rule as a surface's `boundaryEdges()` and the rim the viewport draws; a solid has none. `boundaryOf()` keeps the edges that bound exactly one face of the group: for one face, all its loops; for connected faces, their outline; for groups apart from each other, each one's outline.

The faces are given as face filters or as a face reference — an accessor or a `select()`. A reference is read from the faces as they are now: a face counts when it is the referenced face or lies on the same plane, cylinder, cone, sphere or torus, so a fillet that rebuilt the face later does not break the selection.

### By source object

Restrict the selection to edges that come from one or more specific scene objects — useful when several solids share the scene:

```js
const sa = sketch("xy", () => {
    const b = line([0, 0], [20, 0]);
    const r = line([20, 0], [20, 20]);
    const t = line([20, 20], [0, 20]);
    const l = line([0, 20], [0, 0]);
    coincident(b.end(), r.start());
    coincident(r.end(), t.start());
    coincident(t.end(), l.start());
    coincident(l.end(), b.start());
  })
const a = extrude(40, sa)
const sb = sketch("xy", () => circle([0, 0], 15))
const b = extrude(40, sb)

select(edge().from(a).line())                 // only line edges from `a`
select(edge().from(a, b).circle())            // circle edges from either `a` or `b`
```

`from()` composes with the rest of the chain (AND), so `edge().from(a).onPlane("xy", 0)` returns edges from `a` that also lie on the XY plane.

One instance of a `repeat()` pattern is a source object too: `select(edge().from(r.instance(1)).circle())` scopes the filter to the second instance of the repeat `r`. When the repeat clones a single feature, the instance also forwards that feature's accessors — `r.instance(1).endEdges()` — see [Selecting one instance](/docs/patterns/repeat#selecting-one-instance).

### Negation

```js
edge().notOnPlane("xy")        // edges NOT on the ground plane
edge().notCircle()             // edges that aren't circular
edge().notBelongsToFace(face().cylinder())  // edges NOT on cylindrical faces
edge().notFarthest("z")        // everything but the top layer
edge().notConvex()             // inner corners and smooth transitions only
edge().notBoundary()           // every edge but a surface's open rim
```

## Face filters

Import `face` (and `edge` if using `hasEdge`) from `fluidcad/filters`:

```js
import { face, edge } from 'fluidcad/filters';
```

### By direction

```js
face().parallelTo("xy")        // faces parallel to the XY plane (top/bottom faces)
face().parallelTo("xz")        // faces parallel to the XZ plane (front/back faces)
face().facing("z")             // faces that face within 45° of up
face().facing("-x", 10)        // faces that face nearly straight along −x
```

`facing()` judges a face as a whole, by the mean of its outward normals over its surface, so it works on curved and free-form faces too: a dome faces straight out of its pole and a slot's half-round end faces its middle, and `face().facing("z")` is the top of a dome as well as the top of a box.

A face whose normals cancel out faces nowhere — a bore, the wall of a round boss, a whole sphere. `facing()` never keeps one and `notFacing()` always does; name such a face by its shape instead. The direction is an axis name, a vector or an axis: a plane name such as `"xy"` is not a direction, and `facing("xy")` throws.

### By position

```js
face().onPlane("xy", 30)       // faces on the XY plane at height 30
face().above("xy", 10)         // faces entirely above z = 10
face().below(base.endFaces())  // faces entirely below the plane of a feature's face group
```

Only a flat face is `onPlane()`, including a flat wall that a loft or an imported file stores as a B-spline surface. `above()` and `below()` judge a face on a plane, cylinder, cone, sphere or torus bounded by lines and circular edges by the vertices of its boundary, and any other face by how far it really reaches, so a free-form face that bulges below the plane between its corners is not above it.

### By rank and extremes

```js
face().farthest("z")           // the top face(s) — the layer with the greatest center z
face().nearest("-x")           // the face(s) farthest along −x
face().nth("y", 1)             // the second layer of faces from the −y end
face().largest()               // the faces of greatest area (ties included)
face().smallest("radius")      // the cylinder of least radius
```

Rank filters evaluate over whatever the chain has kept so far: `face().planar().farthest("z")` is the topmost planar face.

### By shape

```js
face().circle()                // round flat faces: the outer boundary is one full circle (a washer counts)
face().cylinder()              // cylindrical faces
face().cone()                  // conical faces
face().sphere(20)              // spherical faces of diameter 20
face().revolved()              // a spline profile turned around an axis
face().extruded()              // the wall of an extruded spline or ellipse
face().freeform()              // everything else: a loft between unlike sections, a sculpted surface
```

As for edges, shapes are told by geometry: a flat wall a loft stores as a B-spline surface is `planar()`, and a round one is a `cylinder()` or `cylinderCurve()`.

### By neighbours

```js
face().adjacentTo(fl.faces())                 // the faces next to a feature's faces, those left out
face().adjacentTo(select(edge().boundary()))  // the faces along a surface's open rim
face().adjacentTo(face().freeform())          // the faces next to any free-form face
face().notAdjacentTo(base.endFaces())         // every face that does not touch the base's top
```

`adjacentTo()` keeps a face that shares an edge with a referenced face, or that a referenced edge bounds; the referenced faces themselves do not match. It takes face or edge filters, or a reference to faces or edges, read as for `between()`.

### By edge properties

```js
face().edgeCount(4)            // faces with exactly 4 edges (rectangular faces)
face().hasEdge(edge().line())  // faces that have at least one straight edge
face().hasEdge(edge().circle(10))  // faces with a circular edge of diameter 10

// or pass a scene object directly
const circularEdges = select(edge().circle());
face().hasEdge(circularEdges)  // faces that share an edge with the selection
```

`hasEdge()` with a selection is slated for removal: `face().adjacentTo(circularEdges)` says the same.

### By source object

```js
select(face().from(a).parallelTo("xy"))       // top/bottom faces of `a`
select(face().from(a, b).cylinder())          // cylindrical faces from either object
```

`from()` composes with other filters as AND. When the surrounding `select()` is cloned by `repeat()` or `mirror()`, the references are remapped to the cloned objects automatically.

One instance of a pattern is a source object too: `select(edge().from(r.instance(1)).circle())` scopes the filter to the second instance of the repeat `r`. When the repeat clones a single feature, the instance also forwards that feature's accessors — `r.instance(1).endEdges()` — see [Selecting one instance](/docs/patterns/repeat#selecting-one-instance).

### Negation

```js
face().notOnPlane("xy", 0)     // faces NOT on the ground plane
face().notCircle()             // non-circular faces
face().notEdgeCount(4)         // faces that don't have exactly 4 edges
face().notHasEdge(edge().arc())  // faces without any arc edges
face().notLargest()            // every face but the largest
```

## Picking one, and growing a chain

A filter can keep one of its matches, and grow from it:

```js
edge().line().at(2)                 // the third straight edge (first(), last() too)
edge().onPlane("xy").withTangents() // grow along edges that continue smoothly, as a filleted outline does
face().cylinder().at(0).withChain() // grow along connected faces: the run of cylindrical faces holding the first
```

`withTangents()` follows neighbours that continue each other without a corner. `withChain()` follows every connected neighbour — edges through a shared vertex, faces through a shared edge — but never leaves what the filter accepts: the filter is the territory, and the seed is what `at(i)`, `first()` or `last()` picks. With none of those, a rank written as the filter's last step plants the seeds:

```js
s.boundaryEdges(edge().at(3).withChain())           // the rim loop that holds rim edge 3
select(edge().boundary().nearest("z").withChain())  // the rim loops that touch the bottom
```

A `withChain()` with no seed at all is an error where it is written, since every match would be a seed and the chain would add nothing.

## Using selections

### With fillet and chamfer

```js
select(edge().onPlane("xy", 30))
fillet(5)                      // fillets the selected edges

select(edge().verticalTo("xy"))
chamfer(2)                     // chamfers vertical edges
```

### With shell

```js
select(face().onPlane("xy", 30))
shell(-3)                      // removes selected face and hollows the solid
```

### With color

```js
select(face().circle())
color("red")                   // colors all circular faces red

select(face().parallelTo("xy"))
color("#3498db")               // hex colors work too
```

### Passing directly

Filters can also go straight into an operation, or narrow a direct selection:

```js
fillet(5, e.endEdges())                    // direct from operation
fillet(5, e.sideFaces(face().cylinder()))   // filter within direct selection
```

## Selections that must survive

A selection is consumed by the operation that uses it. To feed the same faces to two features, select them again for the second. Sketches, planes and axes are only hidden by their first user and can be passed to any number of features — see [Reusable objects](/docs/extra/reusable-objects).
