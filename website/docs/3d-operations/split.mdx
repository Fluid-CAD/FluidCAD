# Split

Split divides a solid along a plane. Keep both sides as separate solids, or keep just one side to trim the model. Use it to divide a housing or separate a model into pieces for printing. Each new cut face is flat and closes the resulting solid.

## In the viewport

1. Finish any open sketch, then click **Split** on the toolbar.
2. Choose the cutting plane in the **Cut** slot. You can pick an origin plane, a plane feature in the viewport or timeline, a planar face, or a straight sketch line. The **Cut** slot is active when the dialog opens.
3. To limit the operation, click the **Solids** slot, then click a face or edge of a target solid, or its feature row in the timeline. Leave **Solids** empty to use all solids in the current scope. Inside a part, that means the solids in that part.
4. Choose **Both**, **Front**, or **Back** to set which pieces to keep. Enter an **Offset** to move the cutting plane along its normal; leave it empty to cut at the selected plane.
5. Check the preview, then click **Apply**. FluidCAD adds a Split feature to the timeline and writes the statement to your file.

The preview shows a translucent cutting plane. With **Front** or **Back** selected, pieces that will be removed appear red. Click the **Cut** or **Solids** slot before picking in the viewport to choose what the next click selects.

Targets are selected by feature. If a feature produced several solids, selecting it can include all of those solids.

To change an existing split, double-click its timeline row. You can replace the cut, change the targets, or adjust the keep side and offset.

The pieces stay in their original positions and touch at the cut. Split does not create a gap or move them apart. Both pieces belong to the Split feature; a later operation targeting that feature acts on all its retained pieces.

## Keep both sides or trim one side

**Front** means the side the cutting plane's normal points toward. **Back** means the opposite side. These directions belong to the plane and do not change when you rotate the view.

| Origin plane | Front side / positive offset direction |
| --- | --- |
| XY | +Z |

A negative **Offset** moves the cut in the opposite direction. For example, selecting an exterior face usually requires an inward offset so the plane passes through the solid instead of touching its surface.

## Split along a sketch line

Use a straight sketch line when the cut needs an angle that is easier to draw than to define with a datum plane.

1. Draw a line across the intended cut in a sketch. Turn on **Guide** before drawing if the line is only for construction.
2. Finish the sketch, open **Split**, and pick the line in the **Cut** slot.
3. Choose the target solids and which side to keep, then click **Apply**.

The line defines an infinite plane perpendicular to its sketch. The cut extends beyond the line's endpoints and through the full solid. Arcs and circles cannot define this plane.

This example cuts a 60 × 40 × 15 block diagonally and keeps **Front**:

![The retained wedge after splitting a block along a diagonal sketch line](/img/docs/3d-operations/split-line.png)

<ExplainedCode code={splitLine} fileName="split-line.part.js" />

For a sketch line, the plane normal is the line direction crossed with the sketch normal. Reversing the line's start and end swaps **Front** and **Back**. Use the red removal preview to confirm which piece will remain.

Applying the split hides the source sketch. Use its timeline eye to show it again; later features can still reference the line. In code, return the line from the sketch callback to access it as `s.geometries.seed`, as shown in the example.

## In code

```js
split('xz');                               // All solids in scope, at the XZ plane.
split(p, body);                             // Only body, at an existing plane p.
split('yz', { keep: 'front' }, body);        // Keep the +X side of the cut.
split('xy', { offset: 12 }, body);          // Cut 12 units above the XY plane.
split(s.geometries.seed, { offset: 3 });     // Offset the plane defined by a line.
```

| Argument | Accepted values |
| --- | --- |
| Cut | `'xy'`, `'xz'`, `'yz'`, a `plane()` feature, a planar face selection, or a straight sketch line |
| Options | `keep`: `'both'` (default), `'front'`, or `'back'`; `offset`: a distance in document units (default `0`) |
| Targets | One or more solid-producing features; omit to use all solids in scope |

See the [API reference](/docs/api/features/3d/split) for the full signature.

## If nothing is split

The cutting plane must pass through the interior of a target solid. A plane that misses a solid or only touches a face or edge leaves that solid unchanged, even when **Front** or **Back** is selected.

If no target is crossed, the original solids remain and the Split row reports **nothing was split**. Change the **Offset**, choose a different cut, or check the **Solids** selection. If there are no solids in scope, create a solid first or place the split inside the part that contains it.

To divide a line or curve within a sketch, use the [sketch Split tool](/docs/sketching/tools/split).
