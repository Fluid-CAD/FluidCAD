# arc()

Draws an arc fully specified by start, end and center guesses. Chain
`.cw()` to flip the sweep side.

**Returns**: [**`SolvedArc`**](/docs/api/types/solved-arc)

## Signatures

```ts
arc(startPoint: Point2DLike, endPoint: Point2DLike, centerPoint: Point2DLike): SolvedArc
```

Draws an arc fully specified by start, end and center guesses. Chain
`.cw()` to flip the sweep side.

| Parameter | Type | Description |
|-----------|------|-------------|
| `startPoint` | [Point2DLike](/docs/api/types/point2dlike) | The start point |
| `endPoint` | [Point2DLike](/docs/api/types/point2dlike) | The end point |
| `centerPoint` | [Point2DLike](/docs/api/types/point2dlike) | The center point |
