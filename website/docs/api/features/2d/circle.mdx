# circle()

Draws a circle at a given center with an optional diameter. The statement
is a solver entity — `.center()` references its center point in
constraints.

**Returns**: [**`SolvedCircle`**](/docs/api/types/solved-circle)

:::tip
See the [guide](/docs/guides/sketching/primitives) for detailed usage examples.
:::

## Signatures

```ts
circle(center: Point2DLike, diameter?: NumberParam): SolvedCircle
```

Draws a circle at a given center with an optional diameter. The statement
is a solver entity — `.center()` references its center point in
constraints.

| Parameter | Type | Description |
|-----------|------|-------------|
| `center` | [Point2DLike](/docs/api/types/point2dlike) | The center point |
| `diameter` | NumberParam | The circle diameter (defaults to 40) *(optional)* |
