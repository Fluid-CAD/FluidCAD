# common()

Computes the common (intersection) of all solids in the current context; surfaces are left alone.

**Returns**: [**`Common`**](/docs/api/types/common)

:::tip
See the [guide](/docs/booleans/introduction) for detailed usage examples.
:::

## Signatures

```ts
common(): Common
```

Computes the common (intersection) of all solids in the current context; surfaces are left alone.

---

```ts
common(...objects: SceneObject[]): Common
```

Computes the common (intersection) of the given solids.

| Parameter | Type | Description |
|-----------|------|-------------|
| `...objects` | [SceneObject](/docs/api/types/scene-object)[] | The objects to intersect — solids; an object that stands for a surface and no solid is refused *(optional)* |
