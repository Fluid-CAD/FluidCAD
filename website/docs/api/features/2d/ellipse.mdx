# ellipse()

Draws an ellipse at a given center.

**Returns**: [**`ExtrudableGeometry`**](/docs/api/types/extrudable-geometry)

:::tip
See the [guide](/docs/guides/sketching/primitives) for detailed usage examples.
:::

## Signatures

```ts
ellipse(center: Point2DLike, rx: NumberParam, ry: NumberParam): ExtrudableGeometry
```

Draws an ellipse at a given center.

| Parameter | Type | Description |
|-----------|------|-------------|
| `center` | [Point2DLike](/docs/api/types/point2dlike) | The center point |
| `rx` | NumberParam | Semi-radius along the plane's X axis |
| `ry` | NumberParam | Semi-radius along the plane's Y axis |
