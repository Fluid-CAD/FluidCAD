# ellipse()

Draws an ellipse at a given center. The ellipse is a solver entity like
a circle: every literal is a guess the constraints drive — the center
(`coincident`, `concentric`, …), the rotation of its RX axis
(`horizontal`/`vertical`, `tangent`) and the two semi-radii
(`radius(el, v, 'x')` for RX, `radius(el, v, 'y')` for RY). `rx` runs
along the ellipse's own RX axis, which starts along the plane's X
direction.

**Returns**: [**`Ellipse`**](/docs/api/types/ellipse)

:::tip
See the [guide](/docs/sketching/primitives/line) for detailed usage examples.
:::

## Signatures

```ts
ellipse(center: Point2DLike, rx: NumberParam, ry: NumberParam, rotation?: NumberParam): Ellipse
```

Draws an ellipse at a given center. The ellipse is a solver entity like
a circle: every literal is a guess the constraints drive — the center
(`coincident`, `concentric`, …), the rotation of its RX axis
(`horizontal`/`vertical`, `tangent`) and the two semi-radii
(`radius(el, v, 'x')` for RX, `radius(el, v, 'y')` for RY). `rx` runs
along the ellipse's own RX axis, which starts along the plane's X
direction.

| Parameter | Type | Description |
|-----------|------|-------------|
| `center` | [Point2DLike](/docs/api/types/point2dlike) | The center point (a guess, like every literal) |
| `rx` | NumberParam | Semi-radius guess along the ellipse's RX axis |
| `ry` | NumberParam | Semi-radius guess along the ellipse's RY axis |
| `rotation` | NumberParam | Guess for the RX axis's angle from the plane's X direction, degrees (default 0) *(optional)* |
