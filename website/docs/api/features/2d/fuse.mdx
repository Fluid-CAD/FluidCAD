# fuse()

Fuses all solids in the current context; surfaces are left alone.

**Returns**: [**`SceneObject`**](/docs/api/types/scene-object)

:::tip
See the [guide](/docs/booleans/introduction) for detailed usage examples.
:::

## Signatures

```ts
fuse(): Fuse
```

Fuses all solids in the current context; surfaces are left alone.

---

```ts
fuse(...objects: SceneObject[]): Fuse
```

Fuses the given solids into one.

| Parameter | Type | Description |
|-----------|------|-------------|
| `...objects` | [SceneObject](/docs/api/types/scene-object)[] | The objects to fuse together — solids; an object that stands for a surface and no solid is refused *(optional)* |
