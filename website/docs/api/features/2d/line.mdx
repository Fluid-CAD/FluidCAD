# line()

Draws a line between two points. The statement is a solver entity whose
literals are guesses — `.start()`, `.end()` and `.mid()` reference its
points in constraints.

**Returns**: [**`SolvedLine`**](/docs/api/types/solved-line)

:::tip
See the [guide](/docs/guides/sketching/introduction) for detailed usage examples.
:::

## Signatures

```ts
line(start: Point2DLike, end: Point2DLike): SolvedLine
```

Draws a line between two points. The statement is a solver entity whose
literals are guesses — `.start()`, `.end()` and `.mid()` reference its
points in constraints.

| Parameter | Type | Description |
|-----------|------|-------------|
| `start` | [Point2DLike](/docs/api/types/point2dlike) | The start point |
| `end` | [Point2DLike](/docs/api/types/point2dlike) | The end point |
