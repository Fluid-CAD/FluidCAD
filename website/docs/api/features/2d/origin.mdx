# origin()

The sketch origin — the plane's local (0, 0) — as a constraint target.
A fixed reference point: `coincident(l.start(), origin())`,
`distance(origin(), c.center(), 40)`, `symmetric(a, b, yAxis())`.
Constraint sketches only.

**Returns**: **`SketchDatum`**
