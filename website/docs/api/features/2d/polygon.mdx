# polygon()

Draws a regular polygon with the given number of sides and diameter.

**Returns**: [**`Polygon`**](/docs/api/types/polygon)

## Signatures

```ts
polygon(numberOfSides: NumberParam, diameter: NumberParam, mode?: PolygonMode): Polygon
```

Draws a regular polygon with the given number of sides and diameter.

| Parameter | Type | Description |
|-----------|------|-------------|
| `numberOfSides` | NumberParam | The number of sides |
| `diameter` | NumberParam | The circumscribed or inscribed diameter |
| `mode` | PolygonMode | `'inscribed'` or `'circumscribed'` (defaults to `'inscribed'`) *(optional)* |

---

```ts
polygon(center: Point2DLike, numberOfSides: NumberParam, diameter: NumberParam, mode?: PolygonMode): Polygon
```

Draws a regular polygon at a given center point.

| Parameter | Type | Description |
|-----------|------|-------------|
| `center` | [Point2DLike](/docs/api/types/point2dlike) | The center point |
| `numberOfSides` | NumberParam | The number of sides |
| `diameter` | NumberParam | The circumscribed or inscribed diameter |
| `mode` | PolygonMode | `'inscribed'` or `'circumscribed'` (defaults to `'inscribed'`) *(optional)* |
