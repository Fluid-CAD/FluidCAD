# project()

Projects 3D objects onto the current sketch plane. In a constraint
sketch the output registers as FIXED reference geometry — constraints
may target it (`tangent(p, l)`, `p.ref(i)`, `p.center()`).

**Returns**: [**`Reference`**](/docs/api/types/reference)

:::tip
See the [guide](/docs/guides/sketching/projection) for detailed usage examples.
:::

## Signatures

```ts
project(...sourceObjects: SceneObject[]): Reference
```
