# rotate()

[2D] Rotates geometry by an angle inside a sketch, about the sketch
cursor (legacy sketches only — constraint sketches require an explicit
center).

**Returns**: [**`SceneObject`**](/docs/api/types/scene-object)

:::tip
See the [guide](/docs/transforms/introduction) for detailed usage examples.
:::

## Signatures

```ts
rotate(angle: NumberParam, ...targets: SceneObject[]): IRotate
```

[2D] Rotates geometry by an angle inside a sketch, about the sketch
cursor (legacy sketches only — constraint sketches require an explicit
center).

| Parameter | Type | Description |
|-----------|------|-------------|
| `angle` | NumberParam | The rotation angle in degrees |
| `...targets` | [SceneObject](/docs/api/types/scene-object)[] | The geometries to rotate (defaults to last object) *(optional)* |

---

```ts
rotate(angle: NumberParam, center: Point2DLike, ...targets: SceneObject[]): IRotate
```

[2D] Rotates geometry by an angle about an explicit center point.

| Parameter | Type | Description |
|-----------|------|-------------|
| `angle` | NumberParam | The rotation angle in degrees |
| `center` | [Point2DLike](/docs/api/types/point2dlike) | The rotation center in sketch coordinates |
| `...targets` | [SceneObject](/docs/api/types/scene-object)[] | The geometries to rotate (defaults to last object) *(optional)* |

---

```ts
rotate(angle: NumberParam, copy: BooleanParam, ...targets: SceneObject[]): IRotate
```

[2D] Rotates geometry by an angle inside a sketch, optionally making a
copy (legacy sketches only — constraint sketches require an explicit
center).

| Parameter | Type | Description |
|-----------|------|-------------|
| `angle` | NumberParam | The rotation angle in degrees |
| `copy` | BooleanParam | Whether to copy instead of move |
| `...targets` | [SceneObject](/docs/api/types/scene-object)[] | The geometries to rotate (defaults to last object) *(optional)* |
