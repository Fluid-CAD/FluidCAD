# intersect()

[3D] The curve where two sets of faces meet, written outside a sketch.
The result holds one wire per connected chain of intersection edges, in
an order that does not change between rebuilds: `edges()`, `start()`
and `end()` read it. The faces are read, not used up.

Faces that only touch — along an edge, tangentially, or lying on each
other — have no intersection curve.

**Returns**: [**`IntersectionCurve`**](/docs/api/types/intersection-curve) \| [**`Reference`**](/docs/api/types/reference)

:::tip
See the [guide](/docs/curves/intersect) for detailed usage examples.
:::

## Signatures

```ts
intersect(first: SceneObject | SceneObject[], second: SceneObject | SceneObject[]): IntersectionCurve
```

[3D] The curve where two sets of faces meet, written outside a sketch.
The result holds one wire per connected chain of intersection edges, in
an order that does not change between rebuilds: `edges()`, `start()`
and `end()` read it. The faces are read, not used up.

Faces that only touch — along an edge, tangentially, or lying on each
other — have no intersection curve.

| Parameter | Type | Description |
|-----------|------|-------------|
| `first` | [SceneObject](/docs/api/types/scene-object) \| SceneObject[] | Faces: a face selection (of solids or surfaces), a surface, a solid (all its faces), or a list of those. |
| `second` | [SceneObject](/docs/api/types/scene-object) \| SceneObject[] | Faces, as `first` takes them, or a `plane()`, taken as infinite. |

intersect(...sourceObjects: SceneObject[]): Reference
