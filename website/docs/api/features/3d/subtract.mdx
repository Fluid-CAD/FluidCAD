# subtract()

Subtracts the second solid from the first (boolean difference). Both
operands are solids; one that stands for a surface and no solid is refused.

**Returns**: [**`SceneObject`**](/docs/api/types/scene-object)

:::tip
See the [guide](/docs/booleans/introduction) for detailed usage examples.
:::

## Signatures

```ts
subtract(object1: SceneObject, object2: SceneObject): SceneObject
```

Subtracts the second solid from the first (boolean difference). Both
operands are solids; one that stands for a surface and no solid is refused.

| Parameter | Type | Description |
|-----------|------|-------------|
| `object1` | [SceneObject](/docs/api/types/scene-object) | The base solid |
| `object2` | [SceneObject](/docs/api/types/scene-object) | The solid to subtract |
