# rotate()

Rotates objects around an axis by an angle.

**Returns**: [**`SceneObject`**](/docs/api/types/scene-object)

:::tip
See the [guide](/docs/transforms/introduction) for detailed usage examples.
:::

## Signatures

```ts
rotate(axis: AxisLike | Connector, angle: NumberParam, ...targets: SceneObject[]): IRotate
```

Rotates objects around an axis by an angle.

| Parameter | Type | Description |
|-----------|------|-------------|
| `axis` | [AxisLike](/docs/api/types/axis-like) \| [Connector](/docs/api/types/connector) | The axis to rotate around — a world axis, an `axis()`, or a connector (its Z axis through its origin) |
| `angle` | NumberParam | The rotation angle in degrees |
| `...targets` | [SceneObject](/docs/api/types/scene-object)[] | The objects to rotate (defaults to last object) *(optional)* |

---

```ts
rotate(axis: AxisLike | Connector, angle: NumberParam, copy: BooleanParam, ...targets: SceneObject[]): IRotate
```

Rotates objects around an axis by an angle, optionally making a copy.

| Parameter | Type | Description |
|-----------|------|-------------|
| `axis` | [AxisLike](/docs/api/types/axis-like) \| [Connector](/docs/api/types/connector) | The axis to rotate around — a world axis, an `axis()`, or a connector (its Z axis through its origin) |
| `angle` | NumberParam | The rotation angle in degrees |
| `copy` | BooleanParam | Whether to copy instead of move |
| `...targets` | [SceneObject](/docs/api/types/scene-object)[] | The objects to rotate (defaults to last object) *(optional)* |
