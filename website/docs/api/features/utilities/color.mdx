# color()

Applies a color to the last selection, or to every face in the current
context when there is no selection (equivalent to `select(face())` first).

**Returns**: [**`SceneObject`**](/docs/api/types/scene-object)

:::tip
See the [guide](/docs/appearance/color) for detailed usage examples.
:::

## Signatures

```ts
color(color: StringParam): SceneObject
```

Applies a color to the last selection, or to every face in the current
context when there is no selection (equivalent to `select(face())` first).

| Parameter | Type | Description |
|-----------|------|-------------|
| `color` | StringParam | The color value (CSS color string) |

---

```ts
color(color: StringParam, ...selections: SceneObject[]): SceneObject
```

Applies a color to the given selections or objects — any mix of face
selections and scene objects; every face of an object's solids is colored.

| Parameter | Type | Description |
|-----------|------|-------------|
| `color` | StringParam | The color value (CSS color string) |
| `...selections` | [SceneObject](/docs/api/types/scene-object)[] | Face selections, or any scene objects *(optional)* |
