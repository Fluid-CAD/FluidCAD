# FaceFilter

Creates a new face filter builder for selecting faces by geometric properties.

```ts
import { face } from 'fluidcad/filters';
```

## Methods

### .onPlane()

```ts
.onPlane(plane: SceneObject | PlaneLike, offset?: number): this
```

Selects faces that lie on the given plane. Besides a standard plane or a
plane feature, any scene object whose first shape is a face works as the
reference — a bucket accessor like `e.endFaces()`, or a select(). The
face is only read to derive its plane (no plane feature is created, and
the referenced geometry is not consumed), so the reference stays valid
even when a later feature reshaped or consumed the face.

Only a flat face lies on a plane, and geometry decides what is flat,
as for `planar`: a flat wall a loft or an import stores as a
B-spline surface is kept. A curved face is on no plane.

| Parameter | Type | Description |
|-----------|------|-------------|
| `plane` | [SceneObject](/docs/api/types/scene-object) \| [PlaneLike](/docs/api/types/plane-like) | The reference plane, plane feature, or face selection. |
| `offset` | number | Optional distance to offset a standard plane before matching. *(optional)* |

### .notOnPlane()

```ts
.notOnPlane(plane: SceneObject | PlaneLike, offset?: number): this
```

Excludes faces that lie on the given plane. Accepts the same references
as `onPlane`, including a face selection to read the plane from.

| Parameter | Type | Description |
|-----------|------|-------------|
| `plane` | [SceneObject](/docs/api/types/scene-object) \| [PlaneLike](/docs/api/types/plane-like) | The reference plane, plane feature, or face selection. |
| `offset` | number | Optional distance to offset a standard plane before matching. *(optional)* |

### .circle()

```ts
.circle(diameter?: number): this
```

Selects round flat faces: flat faces whose outer boundary is one full
circle. Holes are ignored, so a washer and a disc with a square hole
are kept along with a plain disc, and the diameter matched is the
outer circle's. A half disc, or a disc whose rim a cut has split into
arcs, has no full circle around it and is left out.
Geometry decides, not the kernel's storage: a B-spline face that lies flat,
bounded by a B-spline edge that traces a circle, counts as one.

| Parameter | Type | Description |
|-----------|------|-------------|
| `diameter` | number | Optional diameter of the outer circle to match. *(optional)* |

### .notCircle()

```ts
.notCircle(diameter?: number): this
```

Excludes circular (flat, disc-shaped) faces, optionally matching a specific diameter.

| Parameter | Type | Description |
|-----------|------|-------------|
| `diameter` | number | Optional diameter to exclude. *(optional)* |

### .facing()

```ts
.facing(direction: DirectionLike, within?: number): this
```

Selects faces that face a direction. A face faces along its mean
outward normal — the average of its normals over its whole surface,
weighted by area — and is kept when that lies within `within` degrees
of the direction. A flat face faces along its normal, a half-round end
faces its middle, a dome faces straight out of its pole. It works on
every kind of face, so it is the way to say "the top of this free-form
shape": `face().facing('z')` keeps a box's top and a dome, and leaves
out the walls.

A face whose normals cancel out faces nowhere and is never kept,
whatever the angle: a bore, the wall of a round boss, a whole sphere
or torus. A surface's faces face the way the surface is oriented. Under
a repeat or a mirror the direction moves with the copy.

| Parameter | Type | Description |
|-----------|------|-------------|
| `direction` | DirectionLike | `'x'`, `'y'`, `'z'`, `'-x'`, `'-y'`, `'-z'`, a vector, or an axis. A plane name such as `'xy'` is not a direction and throws. |
| `within` | number | The largest angle, in degrees, between the face's mean normal and the direction (default 45). *(optional)* |

### .notFacing()

```ts
.notFacing(direction: DirectionLike, within?: number): this
```

Excludes faces that face a direction (see `facing`). A face that
faces nowhere — a bore, a whole sphere — faces no direction, so it is

| Parameter | Type | Description |
|-----------|------|-------------|
| `direction` | DirectionLike | `'x'`, `'y'`, `'z'`, `'-x'`, `'-y'`, `'-z'`, a vector, or an axis. A plane name such as `'xy'` is not a direction and throws. |
| `within` | number | The largest angle, in degrees, between the face's mean normal and the direction (default 45). *(optional)* |

### .adjacentTo()

```ts
.adjacentTo(...refs: AdjacentArg[][]): this
```

Selects faces next to the given faces or edges: a face that shares an
edge with a referenced face, or that a referenced edge bounds. The
referenced faces themselves do not match.

```js
face().adjacentTo(fl.faces())                 // the neighbours of a fill
face().adjacentTo(select(edge().boundary()))  // the faces along the rim
face().adjacentTo(face().freeform())          // by description
```

Takes face filter builders, edge filter builders, or references to faces
or edges — a bucket accessor or a select(); a face of any one counts.
A filter builder names what `select(builder)` would name among the
bodies in scope. A face reference is read from the faces as they are
now, by identity or by the surface it lies on, so a later fillet that
rebuilt the face does not break the selection; an edge reference names
the edge itself. Pure topology — no size, no position.

| Parameter | Type | Description |
|-----------|------|-------------|
| `...refs` | AdjacentArg[] | Face or edge filter builders, or scene objects whose faces or edges are the reference. *(optional)* |

### .notAdjacentTo()

```ts
.notAdjacentTo(...refs: AdjacentArg[][]): this
```

### .above()

```ts
.above(plane: SceneObject | PlaneLike, offsetOrOptions?: number | { offset?: number; partial?: boolean; }): this
```

Selects faces that are entirely above the given plane (in the direction of its normal). Besides a
standard plane or a plane feature, any scene object whose first shape is
a face works as the reference — a bucket accessor like `base.endFaces()`
— so the half-space follows the referenced feature through edits. The
offset runs along the resolved plane's normal.

A face on a plane, cylinder, cone, sphere or torus that is bounded by
lines and circular edges is judged by the vertices of its boundary.
Any other face — one bounded by a spline or an ellipse, or a free-form
one — is judged by how far it reaches along the plane's normal, so a
face that bulges below the plane between its corners is not above it.
A flat face lying in the plane is on neither side. With `partial`, a
face is kept when any of it is above.

| Parameter | Type | Description |
|-----------|------|-------------|
| `plane` | [SceneObject](/docs/api/types/scene-object) \| [PlaneLike](/docs/api/types/plane-like) | The reference plane, plane feature, or face selection. |
| `offsetOrOptions` | `number \| { offset?: number; partial?: boolean; }` | Offset distance, or an options object with `offset` and `partial`. *(optional)* |

### .below()

```ts
.below(plane: SceneObject | PlaneLike, offsetOrOptions?: number | { offset?: number; partial?: boolean; }): this
```

Selects faces that are entirely below the given plane (opposite to its normal direction). Besides a
standard plane or a plane feature, any scene object whose first shape is
a face works as the reference — a bucket accessor like `base.endFaces()`
— so the half-space follows the referenced feature through edits. The
offset runs along the resolved plane's normal. Faces are judged as for
`above`: by their boundary's vertices when the surface is a
plane, cylinder, cone, sphere or torus bounded by lines and circular
edges, and by how far they reach along the plane's normal otherwise.

| Parameter | Type | Description |
|-----------|------|-------------|
| `plane` | [SceneObject](/docs/api/types/scene-object) \| [PlaneLike](/docs/api/types/plane-like) | The reference plane, plane feature, or face selection. |
| `offsetOrOptions` | `number \| { offset?: number; partial?: boolean; }` | Offset distance, or an options object with `offset` and `partial`. *(optional)* |

### .farthest()

```ts
.farthest(direction: DirectionLike): this
```

Keeps the layer of faces farthest along a direction — every edge whose
center of mass lies at the maximum (within tolerance) along it. A box's
`farthest('z')` is its top face; chain order is evaluation
order, so `face().planar().farthest('z')` ranks only the planar faces.

| Parameter | Type | Description |
|-----------|------|-------------|
| `direction` | DirectionLike | `'x'`, `'y'`, `'z'`, `'-x'`, `'-y'`, `'-z'`, a vector, or an axis. |

### .nth()

```ts
.nth(direction: DirectionLike, index: number): this
```

Keeps the k-th layer of faces along a direction, counting layers of
equal center position from the near end (0-based); a negative index
counts from the far end, so `nth('z', -1)` is `farthest('z')`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `direction` | DirectionLike | `'x'`, `'y'`, `'z'`, `'-x'`, `'-y'`, `'-z'`, a vector, or an axis. |
| `index` | number | Layer index; out-of-range indices match nothing. |
