# FaceFilter

Creates a new face filter builder for selecting faces by geometric properties.

```ts
import { face } from 'fluidcad/filters';
```

## Methods

### .onPlane()

```ts
.onPlane(plane: SceneObject | PlaneLike, offset?: number): this
```

Selects faces that lie on the given plane. Besides a standard plane or a
plane feature, any scene object whose first shape is a face works as the
reference — a bucket accessor like `e.endFaces()`, or a select(). The
face is only read to derive its plane (no plane feature is created, and
the referenced geometry is not consumed), so the reference stays valid
even when a later feature reshaped or consumed the face.

| Parameter | Type | Description |
|-----------|------|-------------|
| `plane` | [SceneObject](/docs/api/types/scene-object) \| [PlaneLike](/docs/api/types/plane-like) | The reference plane, plane feature, or face selection. |
| `offset` | number | Optional distance to offset a standard plane before matching. *(optional)* |

### .notOnPlane()

```ts
.notOnPlane(plane: SceneObject | PlaneLike, offset?: number): this
```

Excludes faces that lie on the given plane. Accepts the same references
as `onPlane`, including a face selection to read the plane from.

| Parameter | Type | Description |
|-----------|------|-------------|
| `plane` | [SceneObject](/docs/api/types/scene-object) \| [PlaneLike](/docs/api/types/plane-like) | The reference plane, plane feature, or face selection. |
| `offset` | number | Optional distance to offset a standard plane before matching. *(optional)* |

### .cylinder()

```ts
.cylinder(diameter?: number): this
```

Selects full cylindrical faces — ones that wrap all the way around their
axis and so carry a circular rim: a hole's bore, a boss's wall.
A partial cylinder (a fillet face, a bore cut open by a slot) is a
`cylinderCurve`. Geometry decides, not the kernel's storage: a
B-spline face that traces a cylinder — a lofted or swept wall, an
imported STEP face — counts as one.

| Parameter | Type | Description |
|-----------|------|-------------|
| `diameter` | number | Optional diameter to match. *(optional)* |

### .notCylinder()

.notCylinder(diameter?: number): this

### .cylinderCurve()

```ts
.cylinderCurve(diameter?: number): this
```

Selects partial cylindrical faces — ones that do not wrap all the way
around their axis: a fillet along an edge, a rounded corner of a pad, a
bore cut open by a slot. A full bore is a `cylinder`. A B-spline
face that traces a cylinder counts, as for `cylinder`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `diameter` | number | Optional diameter to match (a fillet of radius r has diameter 2r). *(optional)* |

### .facing()

```ts
.facing(direction: DirectionLike, within?: number): this
```

Selects faces that face a direction: the outward normal at the face's
centre lies within `within` degrees of it. Works on every kind of face,
so it is the way to say "the top of this free-form shape":
`face().facing('z')` keeps a box's top and a dome's upper faces, and
leaves out the walls. A surface's faces face the way the surface is
oriented. Under a repeat or a mirror the direction moves with the copy.

| Parameter | Type | Description |
|-----------|------|-------------|
| `direction` | DirectionLike | `'x'`, `'y'`, `'z'`, `'-x'`, `'-y'`, `'-z'`, a vector, or an axis. |
| `within` | number | The largest angle, in degrees, between the normal and the direction (default 45). *(optional)* |

### .notFacing()

```ts
.notFacing(direction: DirectionLike, within?: number): this
```

Excludes faces that face a direction (see `facing`).

| Parameter | Type | Description |
|-----------|------|-------------|
| `direction` | DirectionLike | `'x'`, `'y'`, `'z'`, `'-x'`, `'-y'`, `'-z'`, a vector, or an axis. |
| `within` | number | The largest angle, in degrees, between the normal and the direction (default 45). *(optional)* |

### .above()

```ts
.above(plane: SceneObject | PlaneLike, offsetOrOptions?: number | { offset?: number; partial?: boolean; }): this
```

Selects faces that are entirely above the given plane (in the direction of its normal). Besides a
standard plane or a plane feature, any scene object whose first shape is
a face works as the reference — a bucket accessor like `base.endFaces()`
— so the half-space follows the referenced feature through edits. The
offset runs along the resolved plane's normal.

| Parameter | Type | Description |
|-----------|------|-------------|
| `plane` | [SceneObject](/docs/api/types/scene-object) \| [PlaneLike](/docs/api/types/plane-like) | The reference plane, plane feature, or face selection. |
| `offsetOrOptions` | `number \| { offset?: number; partial?: boolean; }` | Offset distance, or an options object with `offset` and `partial`. *(optional)* |

### .ofSolid()

```ts
.ofSolid(): this
```

Selects faces of solids only, leaving out the faces of surfaces —
`select(face().planar().ofSolid())` in a model that also holds an
imported surface. The complement of `ofSurface`.

---

### .ofSurface()

```ts
.ofSurface(): this
```

Selects faces of surfaces only — bodies of faces that enclose no
volume, such as an imported surface — leaving out the faces of solids.
The complement of `ofSolid`.

### .farthest()

```ts
.farthest(direction: DirectionLike): this
```

Keeps the layer of faces farthest along a direction — every edge whose
center of mass lies at the maximum (within tolerance) along it. A box's
`farthest('z')` is its top face; chain order is evaluation
order, so `face().planar().farthest('z')` ranks only the planar faces.

| Parameter | Type | Description |
|-----------|------|-------------|
| `direction` | DirectionLike | `'x'`, `'y'`, `'z'`, `'-x'`, `'-y'`, `'-z'`, a vector, or an axis. |

### .notFarthest()

```ts
.notFarthest(direction: DirectionLike): this
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `direction` | DirectionLike | `'x'`, `'y'`, `'z'`, `'-x'`, `'-y'`, `'-z'`, a vector, or an axis. |

### .nth()

```ts
.nth(direction: DirectionLike, index: number): this
```

Keeps the k-th layer of faces along a direction, counting layers of
equal center position from the near end (0-based); a negative index
counts from the far end, so `nth('z', -1)` is `farthest('z')`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `direction` | DirectionLike | `'x'`, `'y'`, `'z'`, `'-x'`, `'-y'`, `'-z'`, a vector, or an axis. |
| `index` | number | Layer index; out-of-range indices match nothing. |
