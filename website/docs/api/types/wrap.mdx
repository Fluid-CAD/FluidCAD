# Wrap

Extends [`BooleanOperation`](/docs/api/types/boolean-operation)


<details>
<summary>Inherited from [`BooleanOperation`](/docs/api/types/boolean-operation)</summary>

### add()

```ts
add(): this
```

Additive boolean operation — fuses the result with all intersecting scene objects.
Use `.scope()` to target specific objects.

---

### 'new'()

```ts
'new'(): this
```

No boolean operation — keeps the result as a standalone shape,
separate from all other scene objects.

---

### remove()

```ts
remove(): this
```

Subtractive boolean operation — cuts the result from all intersecting scene objects.
Use `.scope()` to target specific objects.

---

### scope()

```ts
scope(...objects: SceneObject[]): this
```

Narrows the boolean operation scope to specific target objects.
Must be chained after `.add()` or `.remove()`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `...objects` | [SceneObject](/docs/api/types/scene-object)[] | The target objects to operate on. *(optional)* |


</details>


### drill()

```ts
drill(value?: boolean): this
```

Enables or disables drill mode, which partitions the sketch into face regions
before wrapping.

| Parameter | Type | Description |
|-----------|------|-------------|
| `value` | boolean | `true` to enable (default), `false` to disable. *(optional)* |

---

### region()

```ts

```

their `region()` declarations gave them. See `IExtrude.region`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `...names` | string[] | Names of regions the sketch declares. *(optional)* |
