# Guides (Construction Geometry)

Sometimes you need geometry in a sketch just for reference — to position other shapes, define tangent lines, or set up construction lines — without including it in the final profile. The `.guide()` method marks any sketch element as construction geometry.

## Making a guide

Call `.guide()` on any sketch shape:

<CodeBlock language="js">{guideBasic}</CodeBlock>

![Guide circle with hexagon](/img/docs/sketching/guide-basic.png)

The guide circle helps you place the hexagon's vertices, but it's excluded from the final sketch output. (In a constraint sketch you can also constrain against a guide — `coincident(s1.start(), guideCircle)` pins a vertex onto it.)

## Use cases

### Alignment reference

<CodeBlock language="js">{guideAlignment}</CodeBlock>

![Guide circle for alignment](/img/docs/sketching/guide-alignment.png)

### Construction lines

```js
sketch("xy", () => {
    const diag = line([0, 0], [100, 100]).guide()   // construction line
    const c = circle([30, 30], 20)                  // actual geometry
    coincident(c.center(), diag)                    // centered somewhere on the diagonal
})
```

Guide geometry is visible in the viewport but does not contribute to the extruded or cut profile.
