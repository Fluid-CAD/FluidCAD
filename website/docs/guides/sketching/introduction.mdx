# 2D Sketching

Every 3D model starts with a 2D sketch. A sketch draws flat shapes on a plane, which you can then extrude, cut, revolve, or sweep into 3D geometry.

FluidCAD sketches are **constraint sketches**: geometry statements draw fully-specified shapes, and constraint statements describe the relationships that must hold between them. A solver then adjusts the geometry until every constraint is satisfied.

```js
import { sketch, line } from 'fluidcad/core';
import { coincident, horizontal, vertical, fix, distance } from 'fluidcad/constraints';

sketch("xy", () => {
    const b = line([0, 0], [100, 0]);
    const r = line([100, 0], [100, 60]);
    const t = line([100, 60], [0, 60]);
    const l = line([0, 60], [0, 0]);
    coincident(b.end(), r.start());
    coincident(r.end(), t.start());
    coincident(t.end(), l.start());
    coincident(l.end(), b.start());
    horizontal(b);
    vertical(r);
    horizontal(t);
    vertical(l);
    fix(b.start(), [0, 0]);
    distance(b.start(), b.end(), 100);
    distance(r.start(), r.end(), 60);
})
```

The third argument `true` marks the sketch as a constraint sketch. Three ideas carry the whole model:

- **Geometry statements are guesses.** `line([0, 0], [100, 0])` places a line at those coordinates, but the coordinates are only a starting point — the solver may move the geometry to satisfy the constraints. Where no constraint applies, geometry simply stays where you drew it.
- **Constraints drive the solve.** `coincident`, `horizontal`, `tangent`, `distance` and friends describe design intent. The solver finds the geometry that satisfies all of them at once. See [Constraints](./constraints) and [Dimensions](./dimensions).
- **Layout convention:** write geometry statements first, then constraints, then derived operations (`offset`, `fillet`, `mirror`, …).

## Sketch planes

A sketch needs a plane to draw on. You can use string names, custom planes, or faces from previous operations.

### String names

```js
sketch("xy", () => { ... })    // XY plane (horizontal, looking down) — same as "top"
sketch("xz", () => { ... })    // XZ plane (vertical, looking from front) — same as "front"
sketch("yz", () => { ... })    // YZ plane (vertical, looking from right) — same as "right"
```

Each plane has an alias and a negative version:

| String | Alias | Negative | Negative alias |
|--------|-------|----------|----------------|
| `"xy"` | `"top"` | `"-xy"` | `"bottom"` |
| `"xz"` | `"front"` | `"-xz"` | `"back"` |
| `"yz"` | `"right"` | `"-yz"` | `"left"` |

### Custom planes

Use `plane()` to create offset or rotated planes:

```js
import { plane } from 'fluidcad/core';

const p = plane("xy", { offset: 50 })           // XY plane shifted 50 units up
const p2 = plane("xz", { rotateX: 45 })         // XZ plane rotated 45° around X
const p3 = plane("xy", { offset: 30, rotateZ: 90 })  // combined
```

### Sketching on a face

You can sketch directly on a face from a previous operation:

```js
const e = extrude(30)

sketch(e.endFaces(), () => {
    circle([0, 0], 30)
})
```

Coordinates in a face sketch are the plane's own 2D coordinates. To place geometry relative to the existing shape, [project](./projection) faces or edges into the sketch and constrain against them — a projected outline is fixed reference geometry the solver never moves.

This is how you build on top of existing geometry — sketch on the top face, then extrude or cut from there.

### Planes from an edge

You can also build a plane from a selected **edge**. The plane sits at a point along the edge, oriented **normal to the edge** — the edge's tangent at that point becomes the plane normal. This is handy for positioning a profile to sweep along a curve or helix:

```js
const e = extrude(30)

plane(e.sideEdges(0), 'start')   // at the edge start
plane(e.sideEdges(0), 0.5)       // halfway along (same as 'middle')
plane(e.sideEdges(0), 1)         // at the end
```

The position is a name — `'start'`, `'middle'`, `'end'` — or a normalized value from `0` (start) to `1` (end). At the start the normal faces **outward** (away from the edge), like a start cap; `'middle'` and `'end'` follow the edge's forward direction.

## The sketch viewport

While a sketch is active, the viewport shows the solver's verdict live:

- **Green edges** — constrained geometry: the solver has locked this entity's position completely.
- **Default-colored edges** — under-constrained geometry that still has degrees of freedom; it rests at your guess coordinates and can be dragged.
- **Red edges** — conflicting constraints that cannot all be satisfied.
- **Badges and dimension labels** — each constraint shows as a small glyph on its geometry; dimensions render as measurements you can double-click to edit.

The status readout reports the remaining **degrees of freedom** (DOF). "Fully constrained" means zero — every entity is locked. See [Dimensions](./dimensions#degrees-of-freedom) for how to read and act on it.

## How sketch faces are created

When a sketch is used by an operation like `extrude()` or `cut()`, FluidCAD turns the 2D geometry into faces using these rules:

- **Overlapping shapes are fused automatically.** If two closed shapes intersect, their outlines merge into a single combined face. You don't need to manually join them.
- **Internal closed shapes are holes.** A closed shape inside another closed shape is treated as a cutout — the inner area is removed. This is how you create rings, mounting holes, and pockets.
- **Open or loose geometry is ignored.** Lines, arcs, or curves that don't form a closed shape are skipped when building faces. They can still be useful as [guides](./guides).

```js
sketch("xy", () => {
    circle([0, 0], 60)         // outer circle
    circle([0, 0], 30)         // inner circle → becomes a hole
})

extrude(20)                    // extrudes the ring between the two circles
```

If you want an internal shape to be solid instead of a hole, chain `.drill(false)` on the operation:

```js
extrude(20).drill(false)       // inner circle is NOT treated as a hole
```
