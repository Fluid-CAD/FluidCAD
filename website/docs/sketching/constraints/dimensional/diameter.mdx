# Diameter

`diameter` sizes a circle — the number a drawing carries for a hole or a shaft.

## In the viewport

1. Click one circle.
2. Click **Dimension**. The label appears across the circle with a ⌀ prefix; type the value and press <kbd>Enter</kbd>.

Double-clicking a circle's edge opens its diameter directly. Double-click the label later to change it.

![A flange bore and a bolt hole sized by diameter](/img/docs/sketching/dimension-diameter.png)

<ExplainedCode code={dimensionDiameter} fileName="flange.part.js">
Two `diameter` statements size the bore and the bolt hole (1 DOF each); the bolt hole's position on the pitch circle comes from `horizontal` and a center-to-center `distance`.
</ExplainedCode>

## In code

```js
diameter(c, 60)                  // 1 DOF
diameter(a, 20)                  // an arc can be dimensioned by diameter too
```

`circle(center, diameter)` already takes a diameter as its guess; the dimension is what makes the size hold when other constraints pull on the circle. Pair several holes with [`equal`](/docs/sketching/constraints/positional/equal) and dimension only one.
