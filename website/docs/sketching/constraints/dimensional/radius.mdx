# Radius

`radius` sizes an arc — a rounded corner, a fillet in the profile, a cam lobe. It is the dimension that completes a [tangent](/docs/sketching/constraints/positional/tangent) arc.

## In the viewport

1. Click one arc.
2. Click **Dimension**. A leader from the center to the rim appears with an R prefix; type the value and press <kbd>Enter</kbd>.

Double-clicking an arc opens its radius directly.

Circles are normally dimensioned by [diameter](/docs/sketching/constraints/dimensional/diameter), arcs by radius — matching how each is annotated on a drawing:

## In code

```js
radius(a, 25)                    // 1 DOF
radius(c, 30)                    // a circle can take a radius too
```
