# Copy

Copy duplicates sketch geometry along one or two directions or around a centre point. The copies take part in the same face-building step as the rest of the sketch, so a copied circle is a hole like the original.

## In the viewport

1. Click **Copy** on the sketch toolbar. The Copy dialog opens docked on the right with a **Type** dropdown, **Linear** or **Circular**, and a **Geometry** slot.
2. Click the sketch edges to copy. Picks accumulate as chips; click a picked edge again, or a chip's **✕**, to drop it.
3. Fill in the direction or the centre and the counts — the fields differ per type, see below. The copies preview in blue as you go, and the statement about to be written shows under the dialog.
4. Click **Apply**.

### Linear

<img src="/img/docs/ui/sketch-copy-linear-dialog.png" alt="The linear Copy dialog: a slot's four edges picked, Direction set to the sketch X axis, Total Count 5, Offset 20" width="240" style={{float: 'right', marginLeft: '1.5rem'}} />

- **Direction** (under **Direction 1**): click the slot, then a sketched line in the viewport, or the sketch's own X or Y axis line. An axis pick shows as the chip *Sketch X axis* and is written as `xAxis()` / `yAxis()`.
- **Total Count**: the number of instances, the original included.
- **Spacing**: **Offset** is the distance between neighbours; **Total** is the whole span, distributed evenly. The mode is shared by both directions.
- **+ Add second direction** adds a **Direction 2** group with its own direction, count and spacing, which turns the row into a grid.
- **Centered** spreads the copies symmetrically about the source instead of running off to one side.
- **Skip** lists the instances to leave out, by index (`1, 3`); in a grid, by cell (`[1, 0], [2, 1]`).

### Circular

<img src="/img/docs/ui/sketch-copy-circular-dialog.png" alt="The circular Copy dialog: a bolt hole picked, Center 0, 0, Total Count 6, Angle Total 360" width="240" style={{float: 'right', marginLeft: '1.5rem'}} />

- **Center**: the X and Y of the centre point, in sketch coordinates.
- **Total Count**: the number of instances, the original included.
- **Angle (°)**: **Total** is the whole sweep, distributed evenly — `360` closes the ring; **Offset** is the angle between neighbours.
- **Skip** lists the instances to leave out, by index.

## By hand

```js
copy("linear", xAxis(), { count: 4, offset: 40 }, g)       // along the sketch's X
copy("linear", [xAxis(), yAxis()], { count: 3, offset: 30 }, g)  // a grid
copy("linear", axis(l), { count: 4, offset: 40 }, g)       // along a sketched line
copy("circular", [0, 0], { count: 8, angle: 360 }, g)      // around a 2D point
```

Options: `count` (instances including the original), `offset` (linear spacing) or `angle` (circular spread), `skip` (indices to leave out), `centered`.

Bare axis strings are **world** axes. On any plane other than XY, use the sketch datums `xAxis()` / `yAxis()` for the sketch's own directions — see [Mirror](/docs/sketching/tools/mirror#sketch-axes-and-world-axes).

## Copies and constraints

The copies register as solver entities tied rigidly to their source: they move when the source moves, and constraining a copy drives the source. Address one with `cp.instance(k)`:

```js
const cp = copy("linear", "x", { count: 3, offset: 40 }, c)
coincident(cp.instance(2).center(), p)      // pins the whole row through the third copy
```

The 3D `copy()` outside a sketch duplicates finished solids — see [Patterns → Copy](/docs/patterns/copy).
