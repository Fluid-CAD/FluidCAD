# Building an Ice Cube Tray

<ViewerEmbed code={iceCubeTrayFinal} entry="ice-cube-tray.fluid.js" />

In this tutorial, you'll build a parametric ice cube tray from scratch, based on the [original design by Product Design Online](https://www.youtube.com/watch?v=I6BooYAo1mg). It covers draft cuts, filleting internal faces, linear patterns, shelling, edge selection with filters, and sweeping a profile along a spine.

Create a new file called `ice-cube-tray.fluid.js` in your project.

## Setup

Start with imports and some variables that define the tray's dimensions. Using variables makes the model parametric — change a number and the whole tray updates.

```js
import { axis, circle, color, cut, extrude, fillet, fuse, line, loft,
    offset, plane, project, repeat, revolve, select, shell,
    sketch, sphere, sweep, translate } from 'fluidcad/core';
import { coincident, horizontal, vertical, fix, distance } from 'fluidcad/constraints';
import { edge, face } from 'fluidcad/filters';

const width = 300;
const length = 104;
const height = 50;
const leftOffset = 7;
const topOffset = 7;
const depth = 30;
const draft = 10;
const thickness = 2;
```

- **`width`** / **`length`** — overall tray dimensions
- **`height`** — how tall the tray walls are
- **`leftOffset`** / **`topOffset`** — how far the first cavity is inset from the tray edge
- **`depth`** — how deep each ice cube cavity is
- **`draft`** — draft angle so the cavity walls taper inward (makes ice easier to release)
- **`thickness`** — wall thickness after shelling

The sketches in this tutorial are **constraint sketches** (the `true` third argument to `sketch(...)`): lines are drawn as guesses, and constraint statements — `coincident` to join endpoints, `horizontal`/`vertical` to square lines up, `fix` to anchor a corner, `distance` to dimension a length — pin them exactly. Because the guesses use the parametric variables, the constraints stay in sync when you change a dimension.

## Step 1: The tray body

The tray starts as a simple rectangular block.

```js
sketch("xy", () => {
    const b = line([-width/2, -length/2], [width/2, -length/2]);
    const r = line([width/2, -length/2], [width/2, length/2]);
    const t = line([width/2, length/2], [-width/2, length/2]);
    const l = line([-width/2, length/2], [-width/2, -length/2]);
    coincident(b.end(), r.start());
    coincident(r.end(), t.start());
    coincident(t.end(), l.start());
    coincident(l.end(), b.start());
    horizontal(b);
    vertical(r);
    horizontal(t);
    vertical(l);
    fix(b.start(), [-width/2, -length/2]);
    distance(b.start(), b.end(), width);
    distance(r.start(), r.end(), length);
})

let e = extrude(height)
```

Four lines form a 300 x 104 rectangle centered on the origin. The `coincident` constraints close the loop, `horizontal`/`vertical` square it up, `fix` anchors the bottom-left corner at `[-width/2, -length/2]`, and the two `distance` dimensions set the width and length — a fully constrained rectangle. `extrude(height)` pushes it up 50 units to create a solid block. We store the result in `e` so we can reference its faces later.

## Step 2: Cut the first cavity

Now we cut a single cavity into the top of the tray, with a draft angle and rounded edges.

### Sketch on the top face

```js
sketch(e.endFaces(), () => {
    const px = -width/2 + leftOffset;
    const py = -length/2 + topOffset;
    const b = line([px, py], [px + 30, py]);
    const r = line([px + 30, py], [px + 30, py + 40]);
    const t = line([px + 30, py + 40], [px, py + 40]);
    const l = line([px, py + 40], [px, py]);
    coincident(b.end(), r.start());
    coincident(r.end(), t.start());
    coincident(t.end(), l.start());
    coincident(l.end(), b.start());
    horizontal(b);
    vertical(r);
    horizontal(t);
    vertical(l);
    fix(b.start(), [px, py]);
    distance(b.start(), b.end(), 30);
    distance(r.start(), r.end(), 40);
});
```

`e.endFaces()` gives us the top face of the extruded block — we sketch directly on it. `px`/`py` place the cavity's bottom-left corner inset from the tray edge by `leftOffset` and `topOffset`; `fix` anchors it there and the `distance` dimensions make the rectangle 30 x 40 units.

### Cut with draft

```js
let c = cut(depth).draft(-draft)
```

`cut(depth)` removes 30 units of material downward from the sketched rectangle. `.draft(-draft)` adds a 10-degree taper so the cavity walls angle inward — this is what makes ice cubes pop out easily.

### Fillet the cavity

```js
fillet(4, c.internalFaces())
```

`c.internalFaces()` selects all the faces inside the cut cavity. `fillet(4)` rounds every internal edge with a 4-unit radius, giving the cavity smooth corners.

![Single cavity cut into the tray](/img/docs/tutorials/ice-cube-tray-step2.png)

## Step 3: Pattern the cavities

One cavity is enough to define the shape — now we repeat it across the tray in a grid.

```js
repeat("linear", ["x", "y"], {
    count: [7, 2],
    length: [255, 50]
});
```

`repeat("linear")` duplicates the previous operation in a grid pattern. The axes `["x", "y"]` define the two directions. `count: [7, 2]` creates 7 columns and 2 rows, and `length: [255, 50]` sets the total span of the pattern in each direction. This produces 14 evenly spaced cavities.

![Grid of 14 cavities](/img/docs/tutorials/ice-cube-tray-step3.png)

## Step 4: Shell the tray

Right now the tray is a solid block with holes cut into it. We need to hollow it out.

```js
shell(-thickness, e.startFaces(), e.sideFaces());
```

`shell(-thickness)` hollows the solid with 2-unit thick walls. The second and third arguments — `e.startFaces()` (the bottom face) and `e.sideFaces()` (all four side faces) — are the faces to remove. This leaves the top rim and the cavity walls intact while creating a thin-walled tray.

![Shelled ice cube tray](/img/docs/tutorials/ice-cube-tray-step4.png)

## Step 5: Add the handle

The final step adds a grip detail along the top edge of the tray using edge selection, filleting, and a sweep.

### Fillet the top edge

```js
select(edge().verticalTo("top").onPlane("yz", { offset: width/2, bothDirections: true }))

fillet(10)
```

`edge()` starts a filter chain. `.verticalTo("top")` finds edges that are vertical relative to the top. `.onPlane("yz", { offset: width/2, bothDirections: true })` narrows to edges on the YZ plane at half the tray's width (the right-hand end). `fillet(10)` rounds this edge with a 10-unit radius, creating a smooth contour.

### Define the sweep spine

```js
const spine = select(
    edge().onPlane("top", height).arc(10).withTangents(),
)
```

This selects the sweep spine along the top rim of the tray. `.onPlane("top", height)` filters to edges at the top, `.arc(10)` picks the arc we just created with the fillet, and `.withTangents()` expands the selection to include every edge tangent-connected to it. Because a fillet produces G1 continuity with its neighbors, this automatically grabs the front and left top edges, giving us a continuous path from a single filter.

![Spine edges selected along the top rim](/img/docs/tutorials/ice-cube-tray-step5-spine.png)

### Sketch the profile and sweep

```js
const p = plane(e.sideFaces(0), -10)
const profile = sketch(p, () => {
    // Upper lip: 2 x 3 notch whose top-right corner sits at [-length/2, height].
    const b1 = line([-length/2, height], [-length/2 - 2, height]);
    const r1 = line([-length/2 - 2, height], [-length/2 - 2, height - 3]);
    const t1 = line([-length/2 - 2, height - 3], [-length/2, height - 3]);
    const l1 = line([-length/2, height - 3], [-length/2, height]);
    // Lower lip: 5 x 2 notch stacked under it, flush with the wall.
    const b2 = line([-length/2, height - 3], [-length/2 - 5, height - 3]);
    const r2 = line([-length/2 - 5, height - 3], [-length/2 - 5, height - 5]);
    const t2 = line([-length/2 - 5, height - 5], [-length/2, height - 5]);
    const l2 = line([-length/2, height - 5], [-length/2, height - 3]);
    coincident(b1.end(), r1.start());
    coincident(r1.end(), t1.start());
    coincident(t1.end(), l1.start());
    coincident(l1.end(), b1.start());
    coincident(b2.end(), r2.start());
    coincident(r2.end(), t2.start());
    coincident(t2.end(), l2.start());
    coincident(l2.end(), b2.start());
    horizontal(b1);
    vertical(r1);
    horizontal(t1);
    vertical(l1);
    horizontal(b2);
    vertical(r2);
    horizontal(t2);
    vertical(l2);
    fix(b1.start(), [-length/2, height]);
    fix(b2.start(), [-length/2, height - 3]);
    distance(b1.start(), b1.end(), 2);
    distance(r1.start(), r1.end(), 3);
    distance(b2.start(), b2.end(), 5);
    distance(r2.start(), r2.end(), 2);
});

const s = sweep(spine, profile)

fillet(0.5, s.sideEdges())
```

`plane(e.sideFaces(0), -10)` creates a plane offset 10 units inward from the first side face — this is where the profile cross-section will be drawn. The profile is an L-shaped step made of two rectangular loops: a 2 x 3 lip anchored at the top of the wall (`[-length/2, height]`) and a 5 x 2 ledge fixed directly beneath it. Each loop gets the same treatment as the earlier rectangles — coincident corners, horizontal/vertical lines, a fixed anchor corner, and two distance dimensions.

![Sweep profile sketch](/img/docs/tutorials/ice-cube-tray-step5-profile.png)

`sweep(spine, profile)` extrudes this profile along the spine path, creating a grip that runs along the tray's top edge. Finally, `fillet(0.5, s.sideEdges())` softens the sharp edges of the sweep.

![Finished ice cube tray](/img/docs/tutorials/ice-cube-tray-final.png)

## What you practiced

- **Parametric variables** — defining dimensions at the top so the whole model adapts when you change a value
- **Constraint sketching** — drawing lines as guesses and pinning them with `coincident`, `horizontal`/`vertical`, `fix`, and `distance` until the sketch is fully constrained
- **`.endFaces()` / `.startFaces()` / `.sideFaces()`** — referencing specific faces of an extrusion
- **`cut().draft()`** — removing material with tapered walls
- **`fillet()` with `internalFaces()`** — rounding all edges inside a cut
- **`repeat("linear")`** — duplicating geometry in a 2D grid pattern
- **`shell()`** — hollowing a solid while removing specific faces
- **`edge()` filters** — selecting edges by orientation and plane position
- **`.withTangents()`** — expanding a selection to include all tangent-connected shapes
- **`sweep()`** — extruding a profile along a curved spine path
