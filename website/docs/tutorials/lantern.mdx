# Building a Lantern

<ViewerEmbed code={lanternFinal} entry="lantern.fluid.js" />

In this tutorial, you'll build a hexagonal lantern from scratch, based on the [original design by TooTallToby](https://www.youtube.com/watch?v=F2C5cfJ2PrQ). It covers a wide range of FluidCAD features: constraint-sketch polygons, draft extrusions, shelling, projecting geometry, pattern cuts, lofting, and revolving.

Create a new file called `lantern.fluid.js` in your project.

## Setup

Start with imports and some variables that define the lantern's dimensions. Using variables makes the model parametric — change a number and the whole lantern updates.

```js
import {
    axis, circle, cut, extrude, line, loft, offset,
    plane, project, repeat, revolve, select, shell,
    sketch, sphere, translate
} from 'fluidcad/core';
import { coincident, equal } from 'fluidcad/constraints';
import { face } from 'fluidcad/filters';

const sides = 6;
const draft = 8;
const windowOffset = 6;
const wallThickness = 7;
const middleHeight = 150;
```

- **`sides`** — number of sides for the lantern's cross-section (hexagonal)
- **`draft`** — draft angle in degrees, so the body tapers as it goes up
- **`windowOffset`** — how far the window cutouts are inset from the face edges
- **`wallThickness`** — wall thickness after shelling
- **`middleHeight`** — height of the main body

The `coincident` and `equal` imports come from `fluidcad/constraints` — constraint statements that tell the sketch solver how geometry relates, rather than where every point sits.

### A polygon helper

The lantern uses five hexagonal profiles of different sizes, so we define one small helper that draws a regular polygon as solved geometry: one `line()` per side with exact vertex guesses on the circumscribing circle (first vertex due east), `coincident()` constraints joining the corners, and `equal()` constraints keeping every side the same length.

```js
function ngon(diameter) {
    const r = diameter / 2;
    const points = [];
    for (let i = 0; i < sides; i++) {
        const a = (2 * Math.PI * i) / sides;
        points.push([r * Math.cos(a), r * Math.sin(a)]);
    }
    const edges = points.map((p, i) => line(p, points[(i + 1) % sides]));
    for (let i = 0; i < sides; i++) {
        coincident(edges[i].end(), edges[(i + 1) % sides].start());
    }
    for (let i = 1; i < sides; i++) {
        equal(edges[0], edges[i]);
    }
    return edges;
}
```

In a constraint sketch every primitive is fully specified up front — those computed points are *guesses*, and the solver keeps geometry exactly where its guesses put it unless a constraint says otherwise. Here the guesses already form a perfect polygon; the constraints record the design intent (closed loop, equal sides) and keep it intact if you later drag or re-dimension an edge.

## Step 1: The middle body

The lantern's main body is a hexagonal prism with a slight taper and hollow walls.

### Extrude with draft

Sketch a hexagon on a plane that's offset 24 units above the origin (to leave room for the base below), then extrude it upward with a draft angle. The `true` argument after the callback makes this a constraint sketch — the mode every sketch in this tutorial uses. The `.new()` keeps the extrusion as a separate solid — we'll need to reference its faces later without interference from other parts.

```js
sketch(plane("xy", { offset: 24 }), () => {
    ngon(100);
})

const middle = extrude(middleHeight).draft(draft).new()
```

![Hexagon sketch](/img/docs/tutorials/lantern-step1-sketch.png)

The draft angle makes the hexagon slightly wider at the top than the bottom, giving the lantern its characteristic tapered shape.

![Tapered hexagonal prism](/img/docs/tutorials/lantern-step1.png)

### Shell it hollow

Select the top and bottom faces, then shell the body to create hollow walls:

```js
select(
    face().onPlane("xy", middleHeight + 24),
    face().onPlane("xy", 24),
);

shell(-wallThickness)
```

`face().onPlane("xy", middleHeight + 24)` finds the top face (at height 174), and `face().onPlane("xy", 24)` finds the bottom face. These two faces are removed, and the rest of the solid is hollowed out with walls of `wallThickness` (7 units).

![Shelled hexagonal body](/img/docs/tutorials/lantern-step1-shell.png)

## Step 2: Cut the windows

Each side of the lantern gets a window. We'll create one window and repeat it around the body.

### Project and offset

To create a window that fits exactly within a side face, we project the face outline onto a sketch, then offset it inward:

```js
sketch(middle.sideFaces(0), () => {
    const outline = project(middle.sideFaces(0)).guide()
    offset(-windowOffset, outline)
})
```

- `middle.sideFaces(0)` gives us the first side face of the hexagonal body — we use it both as the sketch plane and as the geometry to project.
- `project()` traces the face's outline onto the sketch as fixed reference geometry — the solver locks it in place, so nothing can drag it away from the face it came from.

![Projected face outline](/img/docs/tutorials/lantern-step2-project.png)

- `.guide()` marks the projected outline as construction geometry: it steers other statements but doesn't become part of the profile itself.
- `offset(-windowOffset, outline)` shrinks the guide outline inward by 6 units. Since the projection is only a guide, the inset shape is the sketch's sole profile — exactly the window we want to cut.

![Offset window cutout](/img/docs/tutorials/lantern-step2-offset.png)

### Cut and repeat

Cut through the wall, then repeat the cut for all sides:

```js
const c = cut(7)

repeat("circular", "z", {
    count: sides,
    offset: 360 / sides
})
```

`cut(7)` removes 7 units of material (matching the wall thickness). The `repeat("circular")` re-applies this cut around the Z axis, once for each side of the hexagon. `count` includes the original, so `sides` gives us one cut per face.

![Lantern body with windows](/img/docs/tutorials/lantern-step2.png)

## Step 3: The base

The base is two stacked hexagonal layers — a wider bottom tier and a narrower upper tier.

```js
sketch("xy", () => {
    ngon(150);
});

const pl1 = extrude(12)

sketch(pl1.endFaces(), () => {
    ngon(115);
});

extrude(12)
```

- The first sketch draws a hexagon with diameter 150 on the XY plane.
- `extrude(12)` creates a 12-unit tall base slab. It auto-fuses since we didn't use `.new()`.
- The second hexagon (diameter 115) is drawn on the top face of the first layer (`pl1.endFaces()`), then extruded another 12 units. This creates a stepped base.

![Lantern with base](/img/docs/tutorials/lantern-step3.png)

## Step 4: The top

The top mirrors the base with a wider cap, then lofts up to a narrow tip.

### Cap and tip

```js
const topPlane = plane("xy", { offset: middleHeight + 24 });
sketch(topPlane, () => {
    ngon(165);
});

const top = extrude(12)

sketch(plane(topPlane, { offset: 52 + 12 }), () => {
    ngon(50);
});

const tip = extrude(12)
```

- `topPlane` is positioned at the top of the middle body (height 174).
- A wide hexagon (diameter 165) is extruded 12 units to form the cap.
- A small hexagon (diameter 50) is placed 64 units above `topPlane` and extruded 12 units for the tip.

### Loft between cap and tip

```js
loft(top.endFaces(), tip.startFaces())
```

`loft()` creates a smooth transition between the top of the cap and the bottom of the tip. This forms the sloped roof of the lantern.

![Lantern with top and loft](/img/docs/tutorials/lantern-step4.png)

## Step 5: The ring and handle

Finally, a small sphere sits on top, and a ring loops above it as a handle.

### Sphere

```js
let s = sphere(25 / 2)
translate([0, 0, 257], s)
```

A small sphere (diameter 12.5) is placed at the very top of the lantern at height 257.

### Ring

```js
const ringAxis = axis("y", { offsetZ: 290 })

sketch("yz", () => {
    circle([0, 290 + (65 / 2) - (7 / 2)], 7)
});

revolve(ringAxis).new()
```

- `axis("y", { offsetZ: 290 })` creates a Y-axis shifted up to height 290 — this is the center of the ring.
- A small circle (diameter 7) is sketched on the YZ plane, positioned to form the ring's cross-section.

![Ring cross-section sketch](/img/docs/tutorials/lantern-step5-sketch.png)

- `revolve(ringAxis)` rotates this circle around the offset axis, creating a torus (ring). The `.new()` keeps it separate from the rest.

![Finished lantern](/img/docs/tutorials/lantern-final.png)

:::tip[Try it parametric]
Change the `sides` variable to any even number ≥ 4 (e.g. `4`, `6`, `8`) and the whole lantern — body, windows, base, top, and loft — adapts automatically.
:::

## What you practiced

- **Parametric variables** — defining dimensions at the top so the whole model adapts when you change a value
- **`plane()` with offset** — positioning sketches at specific heights
- **Constraint sketches** — building polygon profiles from `line()` primitives with `coincident()` and `equal()` constraints
- **`.draft()`** — tapering an extrusion
- **`.new()`** — preventing auto-fusion to keep parts separate
- **`select()` + `shell()`** — hollowing a solid by removing specific faces
- **`project().guide()` + `offset()`** — tracing a face outline as fixed reference geometry and shrinking it for window cutouts
- **`repeat("circular")`** — repeating a cut around an axis
- **`loft()`** — smoothly connecting two faces at different heights
- **`axis()` with offset + `revolve()`** — creating a ring (torus) by revolving a circle around an offset axis
