# Building an Upper Alignment Clamp

<ViewerEmbed code={upperAlignmentClampFinal} entry="upper-alignment-clamp.fluid.js" />

In this tutorial, you'll build an upper alignment clamp from scratch, based on the [original design by TooTallToby](https://www.youtube.com/watch?v=PP4bR1Kz5FQ). It covers constraint sketches, tangent-arc profiles, sketch datums, projecting reference geometry onto face and offset planes, symmetric extrusions, drilling, 2D mirrors, and mirror repeats.

Create a new file called `upper-alignment-clamp.fluid.js` in your project.

## Setup

Start with imports. This model uses three import sources — core operations, geometric constraints, and selection filters.

```js
import { arc, circle, cut, extrude, fillet, line, mirror, plane, project,
    repeat, sketch, xAxis } from "fluidcad/core";
import { coincident, collinear, concentric, diameter, distance, equal, fix,
    horizontal, radius, tangent, vertical } from "fluidcad/constraints";
import { edge } from "fluidcad/filters";
```

- **`fluidcad/core`** — the modeling operations (sketch, extrude, cut, etc.), the geometry primitives, and the `xAxis` sketch datum
- **`fluidcad/constraints`** — the constraint statements that pin sketch geometry down
- **`fluidcad/filters`** — selection filters for edges and faces

Every sketch in this model is a **constraint sketch** — `sketch(plane, callback)`. In a constraint sketch the coordinates you type are *guesses*: you draw the geometry roughly where it belongs, then state the relationships that define it — this corner touches that one, this line is tangent to that arc, this radius is 13 — and the solver moves the geometry to satisfy them. Most constraints follow the same two-pick thinking as an interactive sketcher: pick two things, state how they relate.

## Step 1: The base body

The clamp starts as a rounded rectangular block: four lines closed into a 120 × 66 rectangle, with every corner rounded.

```js
sketch("top", () => {
    const bottom = line([-60, -33], [60, -33]);
    const right = line([60, -33], [60, 33]);
    const top = line([60, 33], [-60, 33]);
    const left = line([-60, 33], [-60, -33]);

    coincident(bottom.end(), right.start());
    coincident(right.end(), top.start());
    coincident(top.end(), left.start());
    coincident(left.end(), bottom.start());
    horizontal(bottom);
    vertical(right);
    horizontal(top);
    vertical(left);
    fix(bottom.start(), [-60, -33]);
    distance(bottom.start(), bottom.end(), 120);
    distance(right.start(), right.end(), 66);

    fillet(13, bottom, right, top, left);
})
let e = extrude(13)
```

The four `coincident` constraints chain the lines end-to-start into a closed loop, and `horizontal`/`vertical` square it up. That fixes the *shape* but not the *size or place*, so three more statements finish the job: `fix` anchors one corner at `[-60, -33]`, and the two `distance` dimensions set the side lengths to 120 and 66 — centering the rectangle on the origin.

`fillet(13, bottom, right, top, left)` rounds every corner shared by the four lines with a 13-unit arc. Finally `extrude(13)` pushes the plate up 13 units. We store the result in `e` to reference its faces later.

## Step 2: Cut the side notches

Each side of the clamp has a slot-shaped notch cut into it. We'll draw one — two straight flanks blending into a rounded end — and mirror the cut.

### Sketch the notch profile

```js
sketch(e.endFaces(), () => {
    const lower = line([60, -7], [50, -7]);
    const cap = arc([50, -7], [50, 7], [50, 0]).cw();
    const upper = line([50, 7], [60, 7]);
    const mouth = line([60, 7], [60, -7]);

    coincident(lower.end(), cap.start());
    coincident(cap.end(), upper.start());
    coincident(upper.end(), mouth.start());
    coincident(mouth.end(), lower.start());
    horizontal(lower);
    horizontal(upper);
    vertical(mouth);
    tangent(lower, cap);
    tangent(cap, upper);
    fix(cap.center(), [50, 0]);
    radius(cap, 7);
    distance(lower.start(), lower.end(), 10);
});
```

`e.endFaces()` gives us the top face of the base, and the sketch opens directly on it. The profile is two horizontal flank lines, a semicircular `cap` arc, and a vertical `mouth` line sitting on the base's right edge. `arc(start, end, center)` takes fully-specified guesses; `.cw()` picks the clockwise sweep from start to end, so the cap bulges *into* the plate instead of out of it.

This is the first tangent-arc joint in the model: `tangent(lower, cap)` and `tangent(cap, upper)` make each flank flow smoothly into the cap at their shared (coincident) endpoint — the two-pick equivalent of drawing with a tangent-arc tool. The dimensions pin it down: the cap's center is fixed 10 units in from the right edge, `radius(cap, 7)` makes the notch 14 wide, and the `distance` gives the flanks their 10-unit run out to the edge.

![Notch profile sketch](/img/docs/tutorials/upper-alignment-clamp-step2-sketch.png)

### Cut and mirror

```js
const notch = cut()

repeat("mirror", "yz", notch);
```

`cut()` removes the sketched material all the way through. `repeat("mirror", "yz", notch)` mirrors the notch across the YZ plane, creating a matching notch on the opposite side.

![Side notches](/img/docs/tutorials/upper-alignment-clamp-step2.png)

## Step 3: The cylindrical bore

A large cylindrical dome runs through the center of the clamp body, and gets bored out.

### Sketch the semicircle

```js
sketch("front", () => {
    const dome = arc([31, 0], [-31, 0], [0, 0]);
    const flat = line([-31, 0], [31, 0]);

    coincident(dome.end(), flat.start());
    coincident(flat.end(), dome.start());
    collinear(xAxis(), flat);
    fix(dome.center(), [0, 0]);
    radius(dome, 31);
});
```

The profile is a half-disc: an upper semicircular arc closed by a flat line along its diameter. The two `coincident` constraints close the loop, `fix` plants the arc's center at the origin, and `radius(dome, 31)` sizes it.

`collinear(xAxis(), flat)` is new: `xAxis()` is the sketch's built-in horizontal datum axis, and the constraint lays the closing line exactly along it. With both endpoints on the axis and both on the radius-31 circle, the flat is forced to be the full diameter — no extra dimension needed. The arc's guess (start at `[31, 0]`, end at `[-31, 0]`, counterclockwise) puts the dome on the upper side.

![Semicircle sketch](/img/docs/tutorials/upper-alignment-clamp-step3-sketch.png)

### Extrude and bore

```js
const circleExtrude = extrude(66).symmetric();
cut(66, sketch("front", () => {
    const bore = circle([0, 0], 36);
    fix(bore.center(), [0, 0]);
    diameter(bore, 36);
})).symmetric();
```

`extrude(66).symmetric()` extrudes the half-disc 33 units in both directions (66 total, centered). We store it as `circleExtrude` because we'll project its end edge in the next step. The `cut(66, ...)` then bores a 36-diameter hole through the center, also symmetric: `circle([center], d)` takes a center and a *diameter*, and `fix` plus `diameter` make the little bore sketch fully constrained.

![Cylindrical bore](/img/docs/tutorials/upper-alignment-clamp-step3.png)

## Step 4: The pipe mount

The pipe mount is the most complex step — a smooth tangent web connecting the bore dome to a pipe boss. This is where the two-pick constraint style really pays off: every joint of the outline is a `tangent` pick, and the two arcs inherit their size from reference geometry instead of repeating numbers.

### Create the sketch plane

```js
const p = plane("front", { offset: 20 })
```

`plane("front", { offset: 20 })` creates a plane 20 units in front of the front plane.

### Build the profile with tangent geometry

```js
sketch(p, () => {
    const bore = project(circleExtrude.endEdges(edge().arc())).guide()
    const pipe = circle([0, 45], 16).guide()
    const l1 = line([26.644954, 15.844444], [6.876117, 49.088889]);
    const cap = arc([6.876117, 49.088889], [-6.876117, 49.088889], [0, 45]);
    const l2 = line([-6.876117, 49.088889], [-26.644954, 15.844444]);
    const bridge = arc([-26.644954, 15.844444], [26.644954, 15.844444], [0, 0]).cw();

    fix(pipe.center(), [0, 45]);
    diameter(pipe, 16);
    coincident(l1.end(), cap.start());
    coincident(cap.end(), l2.start());
    coincident(l2.end(), bridge.start());
    coincident(bridge.end(), l1.start());
    tangent(l1, cap);
    tangent(cap, l2);
    tangent(l2, bridge);
    tangent(bridge, l1);
    concentric(cap, pipe);
    equal(cap, pipe);
    concentric(bridge, bore);
    equal(bridge, bore);
});
```

Two pieces of reference geometry set the stage:

- `project(circleExtrude.endEdges(edge().arc())).guide()` projects the dome's end edge — the radius-31 arc — onto the sketch plane. Projected geometry comes in **fixed**: it adds no freedom to the sketch, and constraints can lean on it. `.guide()` keeps it out of the profile.
- `circle([0, 45], 16).guide()` is a guide circle marking the pipe: 16 in diameter, fixed 45 above the bore center. It won't be part of the profile either — it exists so the outline can borrow its position and size.

The outline itself is four pieces: two flank lines (`l1`, `l2`) and two arcs — a small `cap` over the pipe and a `bridge` dipping across the dome. The `coincident` chain closes the loop, and the four `tangent` constraints make every joint smooth, so the profile flows line → cap → line → bridge with no kinks.

Then the arcs take their geometry from the references: `concentric(cap, pipe)` + `equal(cap, pipe)` snap the cap onto the pipe guide circle, and `concentric(bridge, bore)` + `equal(bridge, bore)` lay the bridge exactly on the projected bore arc. With both arcs locked to their carriers, the tangency alone decides where the flank lines touch down.

One thing to notice: nothing in the constraints says *which* tangent lines these are — a line tangent to two circles could sit on either side. The **guesses** decide. `l1` is drawn on the right, `l2` on the left, and the solver keeps each line on the side of its guess — placing the guess on the side you mean *is* the choice. Likewise `.cw()` on the bridge picks the short sweep across the top of the dome rather than the long way around the bottom.


## Step 5: The pipe through-hole and mirror

Now we add the pipe itself with a through-hole, then mirror the entire mount to the other side.

### Sketch the pipe profile

```js
sketch(plane("front", { offset: 35 }), () => {
    const outer = circle([0, 45], 16);
    const inner = circle([0, 45], 10);

    fix(outer.center(), [0, 45]);
    concentric(inner, outer);
    diameter(outer, 16);
    diameter(inner, 10);
});
```

On a plane 35 units from the front, two circles are drawn at the pipe center: a 16-diameter outer wall and a 10-diameter bore. `fix` places the outer circle, and `concentric(inner, outer)` ties the bore to it — one anchor, one relationship, instead of two hardcoded centers.

![Pipe profile sketch](/img/docs/tutorials/upper-alignment-clamp-step5-sketch.png)

### Extrude and drill

```js
const pipeLength = -35 + 20;
const e2 = extrude(pipeLength).drill(false);

cut(-pipeLength, sketch(e2.startFaces(), () => {
    const rim = project(e2.startFaces()).guide();
    const bore = circle([0, 45], 10);

    concentric(bore, rim.ref(0));
    diameter(bore, 10);
}));

mirror("front")
```

`extrude(pipeLength)` extends the pipe backward (negative direction) toward the mount. `.drill(false)` makes it a hollow extrusion — the inner circle becomes a hole — with `false` meaning it doesn't drill into the geometry behind it.

The follow-up `cut` finishes the through-hole, and shows the projection-anchoring pattern on a face: the sketch opens on `e2.startFaces()`, whose local origin isn't guaranteed to be the pipe center — so we don't hardcode it. `project(e2.startFaces()).guide()` brings the face's outline in as a fixed reference; both of its edges are circles on the pipe's centerline, so `concentric(bore, rim.ref(0))` locks the cutting circle onto it exactly, wherever the face sits. (`ref(i)` picks one edge of a multi-edge reference.) The cut runs 15 deep, boring through the mount web.

`mirror("front")` then mirrors the pipe mount and through-hole across the front plane, creating a symmetric clamp with pipe mounts on both sides.

![Pipe through-hole and mirror](/img/docs/tutorials/upper-alignment-clamp-step5.png)

## Step 6: Mounting holes and counterbores

The final step adds four mounting holes with counterbores in the corners of the base.

### Through-holes

```js
sketch(e.endFaces(), () => {
    const bolt = circle([47, -20], 7);

    fix(bolt.center(), [47, -20]);
    diameter(bolt, 7);

    const m = mirror("x", bolt);
    mirror("y", bolt, m);
}).name('Hole Sketch');

cut().name('Hole')
```

One 7-diameter circle is constrained 13 units inset from a corner of the base (`[60 - 13, -33 + 13]`). Then the sketch-level mirrors multiply it: `mirror("x", bolt)` reflects it across the horizontal axis, and `mirror("y", bolt, m)` reflects both the original and that copy across the vertical axis — four fully-placed holes from one constrained circle. `cut()` removes material all the way through. `.name()` labels the operations in the model tree.

![Mounting holes sketch](/img/docs/tutorials/upper-alignment-clamp-step6-sketch.png)

### Counterbores

```js
sketch(e.endFaces(), () => {
    const bore = circle([47, -20], 15);

    fix(bore.center(), [47, -20]);
    diameter(bore, 15);

    const m = mirror("x", bore);
    mirror("y", bore, m);
}).name('Counterbore Sketch');

cut(4).name('Counterbore')
```

Larger 15-diameter circles at the same positions create the counterbores — wider, shallow recesses for bolt heads. `cut(4)` removes only 4 units of depth.

## What you practiced

- **`sketch(plane, callback)`** — constraint sketches: geometry statements are guesses, constraint statements decide where everything lands
- **`coincident` chains + `horizontal`/`vertical` + `fix` + `distance`** — closing an outline and pinning its shape, size, and place
- **`fillet(radius, ...lines)`** — rounding the shared corners of a constrained outline
- **`tangent(a, b)`** — smooth joints between coincident lines and arcs, and guesses choosing *which* tangent solution you get where the old qualifiers used to
- **`arc(start, end, center).cw()`** — choosing an arc's sweep side explicitly
- **`collinear(xAxis(), line)`** — constraining against the sketch's built-in datum axes
- **`project(...).guide()`** — projecting model edges and faces in as fixed references, on both offset planes and faces
- **`concentric` + `equal` against references** — sizing and placing profile arcs from reference geometry instead of repeated numbers
- **`.ref(i)`** — picking one edge out of a multi-edge reference
- **`.endFaces()` / `.startFaces()`** — sketching directly on the faces an operation produced
- **`.symmetric()`** — extruding or cutting in both directions from the sketch plane
- **`extrude().drill()`** — creating hollow extrusions
- **`cut()` + `repeat("mirror")`** — cutting and mirroring geometry across a plane
- **`mirror("front")`** — mirroring 3D geometry across a standard plane
- **`mirror("x", ...)` / `mirror("y", ...)` in sketches** — mirroring constrained sketch geometry into symmetric patterns
- **`.name()`** — labeling operations in the model tree
